# 生成和发布

## 生成

先检查，再生成：

```bash
python3 <SKILL_DIR>/scripts/build.py --data portfolio.json --check
python3 <SKILL_DIR>/scripts/build.py --data portfolio.json --out <输出文件夹>
```

`<SKILL_DIR>` 换成这个模板实际装在哪；不要假设当前文件夹就是模板文件夹。只要有 Python 3 就能跑，不用装别的东西。

脚本会生成两份：

| 文件 | 给谁看 | 里面有什么 |
|---|---|---|
| `【网站名】-自己看.html` | 用户自己 | 亮卡、没亮的卡、小任务，能切到 HR 版预览；右上角能换风格看看 |
| `【网站名】-发给HR.html` | HR、面试官 | 只有亮着的卡；没有小任务、没有出处，也切不回系统版；风格只有定好的那一套 |

检查时脚本报的问题要处理：没写出处的亮卡、找不到的截图、偏大的截图、不是 http(s) 开头的链接、像手机号的联系方式、还没填的【待…】。脚本会打出「最高光三条」是哪三张；用户没挑过、脚本自动补的，跟用户说一声。生成后把两份都打开看一遍：卡都在、截图能放大、链接能点开、「一页看完」能打开、手机上也能看。

生成时脚本还会：同一张截图只存一份；长边超过 2000 像素的自动缩小（电脑上有 PIL，或者是 Mac，没有就提醒）；截图放在页面最后，流量慢时页面先能用、图后到；把「网站名｜岗位」和一句话介绍写进网页标题和简介，链接发到微信、Boss 直聘时显示这两样。

## 一页版

两份网页都自带一页版：首屏点「一页看完」就是；网速慢、门还没开的时候，门上也有「不逛了，直接看一页版」。设备显示不了 3D 时（关了图形加速、远程桌面、老电脑），页面自动打开一页版，不会卡在门口。一页版能打印、能存成 PDF：有的公司只收附件，就把 PDF 跟简历一起发。

## 发布之前，先查隐私

逐张卡看一遍，提醒用户去掉或打码：手机号、微信号、邮箱、身份证、住址；公司内部数据、客户名字、还没公开的业绩。发出去的链接谁都能打开。

## 发布

- 只有用户说要发布，才发布。本地生成好，不能说成「已经上线」。
- 发的是「发给HR」那一份。
- 用 agent 自带的发布功能。豆包电脑版：右边预览区右上角点「发布」，再点「确认发布」，完成后就能拿到分享链接。别的 agent 按它自己的发布按钮来。
- agent 没有发布功能：告诉用户可以直接把 html 文件发给 HR；用户要求时，再帮他放到 GitHub Pages 这类托管上。
- 发布后打开链接再看一遍：手机上能打开，亮卡都在，没有灰卡。

## 链接怎么用（告诉用户）

- 放进简历；
- 跟 HR 开聊时发过去；
- 面试时打开，一张卡讲一件事；
- 面试完追问进度时，可以说「我可以把作品发您，麻烦您帮我递一下」。
