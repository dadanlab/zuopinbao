# 个人作品堡

用 AI 做一座能逛的求职作品集：中间是你的作品堡，周围六个区域，每个区域是一面能力卡墙。卡片照你想投的岗位来定，用你做过的事一张张点亮。

不需要会 3D 建模，也不需要会写代码。

## 怎么用

把下面这句话发给你常用的 agent（能装模板、能联网、能运行 Python 的那种）：

```text
帮我装上这个作品堡模板，然后一步步带我做：https://github.com/dadanlab/zuopinbao
```

装好以后，它会一题一题问你，你选一选、答一答，把截图、链接、经历丢给它就行，不用排版。

## 它会帮你做什么

1. **照岗位定卡**：扒 10 家头部公司这个岗位的招聘要求，把反复出现的要求分到技能、经验、行业认知、个人资源、软技能、个人背景六个区域，一项一张卡。
2. **帮你把卡点亮**：引导你回顾学校、实习、工作和生活里做成过的事，提炼成高光：哪个项目、哪个环节、做了什么、结果怎么样，配上截图和链接。没实习也没关系，闪光时刻也算。
3. **告诉你缺什么**：没亮的卡，给你派一个两周内做得完的小任务，做完就能点亮。
4. **生成两份网页**：
   - 「自己看」：亮的、没亮的卡和小任务都在，看自己的进度；
   - 「发给HR」：只有亮着的卡，发给 HR、放进简历、面试时打开讲，都用这一份。

   两份都有「一页看完」：赶时间的人、打不开 3D 的电脑，看一页版就行，也能存成 PDF。
5. **四套风格选一套**：晨雾紫、奶油杏、薄荷绿、海盐蓝，按你投的岗位推荐，「自己看」那份能当场换着看。

## 放心的地方

- 只用你给的东西，不编经历、不编数字。
- 学历、年限这种门槛不会挂出来；个人背景只放加分的，排在最后。
- 发布前会提醒你把手机号、公司内部数据这类信息去掉。

## 文件

- `SKILL.md`：给 agent 看的总说明
- `references/`：引导话术、扒招聘要求的方法、高光怎么写、小任务怎么派、怎么发布、以后怎么加卡
- `assets/template.html`：页面模板
- `scripts/build.py`：生成页面的脚本（只用 Python 标准库）
- `examples/portfolio.example.json`：数据示例（里面的人和经历都是编的）

## 出处

- 方法来自大胆在小红书分享的求职干货：扒 10 家头部公司的招聘要求、匹配度和高价值、从闪光时刻里提炼、缺哪个补哪个。
- 3D 部分用的是 three.js（MIT 协议），已经打包在页面里，断网也能打开。
